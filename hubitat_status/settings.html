🏠 Hubitat status

Display your home status at a glance.

Connect to Hubitat Maker API device data, choose the status blocks to show, and create a compact home overview dashboard for your e-paper display.

🔑

Maker API setup

In InkyPi, open the API Keys page using the key icon and add a key named HUBITAT_DEVICES_URL. Paste your full local Hubitat Maker API Get All Devices URL as its value.

Example: http://hubitat.local/apps/api/94/devices/all?access_token=your-token

📝

Dashboard heading

Set the title shown on the rendered home-status dashboard.

Optional. Leave blank to use the default Hubitat Status heading.

Display sections
